Core subsystems

S1 · IRONMIND

The mind

A local AI persona wired into everything it runs — reads project files (sandboxed, read-only), holds a real conversation, never phones home.

S2 · COCKPIT HUD

Command deck

A floating modular widget grid — board, focus queue, chat, system, notes — snapped together on a 12-column desktop layout.

S3 · MEMORY

Semantic recall

Local vector embeddings give Ironmind real memory of past conversations and context, not just a scrollback log.

S4 · VISION

Sight

A local vision model reads photos — ID a part, sanity-check a repair — no cloud upload, no API bill.

S5 · BOARD & FOCUS

Command board

Every project with its next action, plus a deterministic priority queue: overdue, then due-today, then everything else.

S6 · REMOTE

Reach anywhere

Tailscale links phone + PC on a private mesh, gated behind auth. Secure by default, no open ports.
